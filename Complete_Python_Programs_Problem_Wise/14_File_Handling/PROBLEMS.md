# 14 File Handling
## Problems
1. **01_Employee_File_Report.py** — Store employee records in a text file and generate a report.
2. **02_Student_File_Management.py** — Create, read, search and update student records in a file.
3. **03_Log_File_Analyzer.py** — Analyze a log file for error, warning and information counts.
4. **04_CSV_Sales_Report.py** — Read sales data from CSV and generate totals and summaries.
5. **05_JSON_Employee_Database.py** — Store employee records in JSON and implement CRUD-style operations.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
