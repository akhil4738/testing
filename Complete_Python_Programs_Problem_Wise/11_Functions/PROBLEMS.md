# 11 Functions
## Problems
1. **01_Employee_Payroll_Functions.py** — Build a payroll system using separate functions for gross pay, deductions, tax and net pay.
2. **02_Student_Result_Functions.py** — Use functions to calculate total, percentage, grade and class statistics.
3. **03_Function_Based_Calculator.py** — Create a reusable calculator using functions and a menu-driven interface.
4. **04_Recursive_Number_Problems.py** — Solve factorial, Fibonacci, digit sum and reverse using recursive functions.
5. **05_Function_Arguments_Project.py** — Demonstrate positional, keyword, default and variable-length arguments in a practical billing system.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
