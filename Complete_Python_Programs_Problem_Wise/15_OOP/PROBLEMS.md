# 15 OOP
## Problems
1. **01_Employee_Class.py** — Create an Employee class with constructor, methods, salary calculation and display.
2. **02_Bank_Account_Class.py** — Build a BankAccount class supporting deposit, withdrawal, transfer and transaction history.
3. **03_Student_Result_Class.py** — Build a Student class that stores marks and calculates results.
4. **04_Inheritance_Payroll.py** — Use inheritance for different employee types with different salary rules.
5. **05_Polymorphism_Project.py** — Demonstrate polymorphism through multiple payment methods.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
