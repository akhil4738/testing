# 12 Modules and Packages
## Problems
1. **01_Employee_Module_Project.py** — Create a small employee utility workflow using imported standard modules.
2. **02_Date_Module_Project.py** — Build an employee joining-date and experience calculator using datetime.
3. **03_Math_Module_Project.py** — Create a financial calculator using math functions.
4. **04_Custom_Module_Demo.py** — Design a custom utility module and import its functions into a main program.
5. **05_Package_Project.py** — Organize reusable utilities into package-style modules and use them from a main application.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
