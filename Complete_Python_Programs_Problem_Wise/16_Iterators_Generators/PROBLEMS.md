# 16 Iterators Generators
## Problems
1. **01_Custom_Iterator.py** — Create a custom iterator for employee records.
2. **02_Number_Generator.py** — Create generators for filtered number sequences.
3. **03_Large_File_Generator.py** — Process a large file line-by-line using a generator approach.
4. **04_Generator_Pipeline.py** — Build a generator pipeline for filtering and transforming sales data.
5. **05_Generator_Report.py** — Generate reports lazily from a sequence of records.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
