# 05 Patterns
## Problems
1. **01_Number_Pyramid.py** — Generate a number pyramid with rows controlled by the user.
2. **02_Pascal_Triangle.py** — Generate Pascal's triangle without importing external libraries.
3. **03_Diamond_Pattern.py** — Generate a symmetric diamond pattern with configurable rows.
4. **04_Hollow_Square.py** — Generate a hollow square and explain the boundary conditions through code.
5. **05_Character_Pattern.py** — Generate an alphabet pattern using nested loops and character arithmetic.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
