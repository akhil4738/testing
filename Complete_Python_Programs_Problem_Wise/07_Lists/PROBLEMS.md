# 07 Lists
## Problems
1. **01_Student_Marks_List.py** — Manage a list of marks and calculate statistics, grades and failed subjects.
2. **02_Employee_Salary_List.py** — Process employee salaries and find average, highest, lowest and salaries above average.
3. **03_Remove_Duplicates.py** — Remove duplicates from a list while preserving original order.
4. **04_Shopping_Cart.py** — Build a shopping cart using lists with quantities, prices, discounts and final bill.
5. **05_List_Search_Sort.py** — Implement searching and sorting operations on a list without relying entirely on built-ins.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
