# 21 SQLite Database
## Problems
1. **01_Employee_CRUD.py** — Build a SQLite employee CRUD application.
2. **02_Student_Database.py** — Create tables, insert students and generate result queries.
3. **03_Inventory_Database.py** — Manage products, stock and price using SQLite.
4. **04_Banking_Database.py** — Implement account and transaction tables.
5. **05_Sales_Database_Project.py** — Store sales and generate summary reports using SQL queries.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
