# 02 Operators
## Problems
1. **01_Salary_Analysis.py** — Calculate gross salary, deductions, annual salary and percentage contribution of each deduction.
2. **02_Loan_EMI_Components.py** — Accept principal, annual interest and tenure; calculate monthly interest, total interest and payment estimates.
3. **03_Electricity_Bill.py** — Calculate an electricity bill using slab-based units, fixed charges and tax.
4. **04_Shopping_Discount.py** — Calculate discounts for multiple products and compare original and discounted totals.
5. **05_BMI_Calculator.py** — Calculate BMI, convert units where needed, and print the category with supporting values.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
