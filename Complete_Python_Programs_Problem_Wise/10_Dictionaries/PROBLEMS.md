# 10 Dictionaries
## Problems
1. **01_Employee_Database.py** — Create a dictionary-based employee database with search, update and report operations.
2. **02_Student_Result_System.py** — Store student marks in nested dictionaries and generate result reports.
3. **03_Inventory_Manager.py** — Build an inventory system with product quantities, prices, stock alerts and updates.
4. **04_Frequency_Analyzer.py** — Build a word-frequency analyzer using dictionaries.
5. **05_Banking_Dictionary.py** — Create a simple account manager using dictionaries for deposit, withdrawal and balance checks.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
