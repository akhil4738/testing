# Complete Python — Problem-Oriented Practice

This version is designed for serious training rather than tiny syntax demonstrations.

## Structure
- 25 concept-wise folders
- 5 problem-solving programs per folder
- 125 main problem programs
- Each `.py` program is designed as a multi-step exercise and is substantially longer than a minimal syntax example.
- Every module has a `PROBLEMS.md` file containing the problem statements.

## Recommended learning path
Basics → Operators → Conditions → Loops → Patterns → Strings → Lists → Tuples → Sets → Dictionaries → Functions → Modules → Exceptions → Files → OOP → Iterators/Generators → Decorators → Regex → Date/Time → Math/Random → SQLite → Multithreading → Advanced Python → Packages/Environment → Mini Projects

## Training method
For each program:
1. Read only the problem statement.
2. Try writing the solution yourself.
3. Run the supplied solution.
4. Change the inputs and test edge cases.
5. Add one additional feature.
6. Refactor the program using functions/classes after learning those concepts.
