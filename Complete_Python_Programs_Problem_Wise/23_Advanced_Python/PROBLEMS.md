# 23 Advanced Python
## Problems
1. **01_Comprehension_Project.py** — Use list, set and dictionary comprehensions in a data-processing project.
2. **02_Copy_Project.py** — Demonstrate shallow and deep copy with nested employee records.
3. **03_Context_Manager_Project.py** — Create and use a context manager for resource handling.
4. **04_Zip_Enumerate_Project.py** — Process paired records using zip and enumerate.
5. **05_Unpacking_Project.py** — Use advanced unpacking in a practical data transformation problem.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
