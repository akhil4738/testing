# 25 Mini Projects
## Problems
1. **01_Employee_Management_System.py** — Build a console employee management system with add, search, update, delete and report features.
2. **02_Student_Management_System.py** — Build a student management system with marks, grades and search features.
3. **03_Expense_Tracker.py** — Build an expense tracker with categories, totals and monthly summaries.
4. **04_Inventory_Management_System.py** — Build an inventory application with stock operations and low-stock reports.
5. **05_Banking_System.py** — Build a console banking system with accounts, transactions, validation and reports.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
