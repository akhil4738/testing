# 24 Packages and Environment
## Problems
1. **01_Project_Structure.py** — Create a package-style project structure with reusable modules.
2. **02_Requirements_Workflow.py** — Create and document a requirements workflow for a Python project.
3. **03_Virtual_Environment_Guide.py** — Demonstrate commands and project structure for a virtual environment.
4. **04_Package_Utilities.py** — Build reusable utility modules for validation and formatting.
5. **05_Installable_Project.py** — Prepare a small package project with metadata and reusable code.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
