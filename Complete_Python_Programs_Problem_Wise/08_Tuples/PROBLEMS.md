# 08 Tuples
## Problems
1. **01_Employee_Record_Tuple.py** — Store employee records using tuples and generate a formatted report.
2. **02_Tuple_Statistics.py** — Analyze a tuple of numbers and calculate statistics without converting it to a list.
3. **03_Nested_Tuple_Report.py** — Process nested tuples representing students and their marks.
4. **04_Tuple_Merge_Search.py** — Merge tuple data and search for records based on a key.
5. **05_Tuple_Data_Validation.py** — Validate tuple-based records and separate valid and invalid entries.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
