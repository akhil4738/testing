# 06 Strings
## Problems
1. **01_Password_Analyzer.py** — Analyze a password for length, uppercase, lowercase, digit and special-character requirements.
2. **02_Text_Statistics.py** — Analyze a paragraph for words, characters, spaces, vowels, consonants and repeated words.
3. **03_Email_Validator.py** — Validate a simple email format using string operations and conditions.
4. **04_Palindrome_Sentence.py** — Check whether a sentence is a palindrome after normalization.
5. **05_String_Compression.py** — Implement basic run-length compression for a string.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
