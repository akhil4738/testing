# 03 Conditional Statements
## Problems
1. **01_Employee_Appraisal.py** — Determine appraisal percentage and revised salary using performance rating and years of experience.
2. **02_Admission_Eligibility.py** — Check college admission eligibility using marks in multiple subjects and category-independent rules.
3. **03_Insurance_Premium.py** — Calculate insurance premium based on age, vehicle type, claim history and coverage.
4. **04_Bank_Loan_Eligibility.py** — Evaluate loan eligibility from salary, credit score, existing EMI and requested amount.
5. **05_Income_Tax_Slab.py** — Calculate tax using progressive slabs and show each slab contribution.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
