# 19 Dates and Time
## Problems
1. **01_Employee_Experience.py** — Calculate employee experience from joining date.
2. **02_Attendance_Date_Report.py** — Generate attendance dates and calculate working-day information.
3. **03_Age_Calculator.py** — Calculate exact age from date of birth.
4. **04_Date_Difference_Project.py** — Calculate date differences for project deadlines.
5. **05_Scheduling_System.py** — Build a simple appointment scheduling validator.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
