# 01 Basics
## Problems
1. **01_Student_Profile.py** — Create a student profile program that accepts name, age, course, college and marks, then prints a formatted report.
2. **02_Employee_Salary.py** — Create an employee salary calculator using basic salary, HRA, DA, deductions and net salary.
3. **03_Bill_Generator.py** — Create a shopping bill for multiple products and display subtotal, discount, GST and final amount.
4. **04_Movie_Ticket.py** — Create a movie ticket calculator based on number of tickets, ticket price, snacks and service charge.
5. **05_Travel_Expense.py** — Create a travel expense calculator for transport, food, hotel and miscellaneous expenses.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
