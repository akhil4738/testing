# 09 Sets
## Problems
1. **01_Employee_Departments.py** — Compare employees belonging to different departments using set operations.
2. **02_Course_Enrollment.py** — Find common, unique and exclusive students across multiple courses.
3. **03_Skill_Matching.py** — Compare candidate skills with required job skills and calculate missing skills.
4. **04_Duplicate_Data_Audit.py** — Use sets to audit duplicate IDs across multiple data sources.
5. **05_Set_Based_Access_Control.py** — Model user roles and permissions using sets and determine effective permissions.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
