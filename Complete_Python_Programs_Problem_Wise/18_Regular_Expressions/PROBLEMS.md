# 18 Regular Expressions
## Problems
1. **01_Email_Extractor.py** — Extract and validate email addresses from a block of text.
2. **02_Phone_Validator.py** — Validate Indian-style phone numbers using regular expressions.
3. **03_Log_Analyzer.py** — Extract dates, levels and error messages from application logs.
4. **04_Password_Regex.py** — Validate password complexity using regular expressions.
5. **05_Data_Extractor.py** — Extract IDs, amounts and dates from semi-structured text.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
