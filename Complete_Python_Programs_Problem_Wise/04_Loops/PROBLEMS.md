# 04 Loops
## Problems
1. **01_Number_Analysis.py** — Read N numbers and calculate sum, average, maximum, minimum, even count, odd count and prime count.
2. **02_Employee_Attendance.py** — Process attendance for several employees and produce individual attendance percentages and eligibility.
3. **03_Sales_Report.py** — Read daily sales for a month and generate total, average, best day, worst day and target achievement.
4. **04_Student_Marks_Report.py** — Process marks for multiple students and generate totals, percentages, grades and class statistics.
5. **05_Menu_Driven_Calculator.py** — Build a menu-driven calculator that continues until the user chooses exit.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
