# 22 Multithreading
## Problems
1. **01_Two_Employee_Tasks.py** — Run two independent employee processing tasks using threads.
2. **02_File_Processing_Threads.py** — Process multiple files concurrently.
3. **03_Thread_Join_Project.py** — Use join to coordinate multiple worker threads.
4. **04_Daemon_Background_Task.py** — Create a background monitoring task using a daemon thread.
5. **05_Threaded_Downloader_Simulation.py** — Simulate concurrent downloads with worker threads.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
