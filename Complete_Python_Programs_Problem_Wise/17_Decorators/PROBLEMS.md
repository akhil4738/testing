# 17 Decorators
## Problems
1. **01_Execution_Time_Decorator.py** — Create a decorator that measures function execution time.
2. **02_Login_Decorator.py** — Create a decorator that checks whether a user is logged in before executing a function.
3. **03_Logging_Decorator.py** — Log function calls, arguments and return values.
4. **04_Authorization_Decorator.py** — Implement role-based authorization using decorators.
5. **05_Multiple_Decorators_Project.py** — Combine logging, validation and authorization decorators in a practical application.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
