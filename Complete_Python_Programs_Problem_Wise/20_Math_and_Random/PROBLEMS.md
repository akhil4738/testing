# 20 Math and Random
## Problems
1. **01_Loan_Calculator.py** — Use math operations to build a loan calculation utility.
2. **02_Statistics_Calculator.py** — Calculate mathematical statistics for a dataset.
3. **03_Number_Guessing_Game.py** — Build a number guessing game with attempts and score.
4. **04_Otp_Generator.py** — Generate a random numeric OTP and validate it.
5. **05_Random_Test_Data.py** — Generate random test records for employee/student data.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
