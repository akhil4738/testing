# 13 Exception Handling
## Problems
1. **01_Bank_Transaction_Safety.py** — Handle invalid amounts, insufficient balance and invalid input in a banking workflow.
2. **02_Student_Input_Validation.py** — Safely process student marks and reject invalid values.
3. **03_File_Error_Handler.py** — Handle missing files, permission errors and invalid content.
4. **04_Division_Service.py** — Create a robust division service that handles multiple runtime errors.
5. **05_Custom_Exceptions_Project.py** — Create custom exceptions for employee salary, age and department validation.

Each program is intended as a problem-solving exercise, not a one-line demonstration.
